애니메이션 구현 목록 — 현재 존재하는 상호작용 기준
물병: 무릎 굽힘 → 물줄기·수위 상승 → 획득물 제시 → 수집 완료.
냄비/음식 제작: 작업 포즈 → 냄비·기포·증기 → 완성품 → 가방 보상.
먹기/마시기: 입으로 물건 이동 → 섭취 → 회복. 연속 입력/도구 변경 방지.
삽/곡괭이/칼: 준비 → 내리치기/베기 → 흙·조각 → 재료 획득.
도끼/창/활: 도구별 궤적, 예비 자세, 타격/발사, 동물 반응과 퇴장.
낚시: 그림자 → 캐스팅 → 찌 움직임 → 입질 입력 → 끌어올림 → 실제 어종 그림 제시.
채집/가방/바구니: 웅크려 집기 → 아이템 들어 보이기 → 가방. 바구니는 묶음 채집.
횃불: 꺼내 들기 → 불빛 떨림·주변 시야 변화.
가방: 그림 슬롯 → 선택 강조 → 확대 미리보기 → 손에 들기/섭취. 30종 독립 그림.
보관함: 그림 클릭 → 옮기는 포즈 → 공유 수량 변경.
환경: 별도 포말·수면 반사·불꽃·잎·풀·머리카락. 고정 바위/텐트는 이동하지 않음.

주의할 범위
위 영상의 모든 기능을 구현했다고 주장하지 않는다. 도감은 현재 획득 아이템 기록이며 생물별 서식·계절 데이터베이스는 아니다.
영상의 캐릭터나 자산을 복제하지 않았다. 물 채우기와 동물 사냥은 우리 생존 게임의 자체 행동이며 원작에 같은 기능이 있다고 간주하지 않는다.
게임 속 간략한 끓이기 연출의 몇 초는 실제 소독·냉각 시간을 뜻하지 않는다.

캐릭터
하준: 갈색 삐죽머리, 노란 충암초 하복 티셔츠, 짙은 반바지, 흰 운동화.
여름: 짧은 검정머리, 주황 티셔츠, 남색 반바지, 노란 신발. 사용자 요청으로 안경 제거. 24개 표정·걷기·행동 프레임 별도 적용.
