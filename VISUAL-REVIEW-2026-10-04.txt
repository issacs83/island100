무인도 100일 — 직접 플레이 및 그래픽 검토

검증 범위
Nintendo Direct 전체 자막을 읽고 기능별 대응표를 작성했으나, 영상을 연속으로 끝까지 시청하며 모든 애니메이션을 분석한 것은 아니다. 이번에도 제작/아이템 꾸미기, 이동, 후반 탐험 구간의 선택 장면을 재확인했다. 모든 장면/모든 기능을 반영했다는 표현을 사용하지 않는다.
참조: https://www.youtube.com/watch?v=Ie4WZCLbtVs

직접 발견한 문제와 수정
1. 도구 그림 중심이 손에 붙어 손잡이를 쥐지 못함 → 13종 도구별 손잡이 좌표를 분리, 좌우 반전과 손 겹침 처리.
2. 첫 수정에서 창이 과도하게 큼 → 136에서 92로 축소, 도끼 66/곡괭이 72/삽 78로 조정. 크기는 몸과 같은 원근 배율 사용.
3. 생성 시트의 실제 행 경계가 균등하지 않아 신발 잘림 → 하준 0/295/543/768, 여름 0/274/516/768 구간으로 분리. 행마다 몸 높이 정규화.
4. 회색 타원뿐인 작은 돌 → 보유 아이템과 같은 돌 이미지로 교체.
5. 도끼 올리자마자 나무 내구도 감소 → 타격 시점에 감소, 마지막 타격 때 쓰러짐.
6. 얇은 선만 흔들리는 파도 → 들어오는 얕은 물, 포말, 남는 물기, 느린 후퇴로 분리. 파도 소리도 같은 7.5초 주기를 참조.
7. 솔로 여름 NPC 고정 → 낮 탐사/원거리 추종/야간 귀환/캠프 휴식, 장애물 우회. 탐사 지점 도달 시 지도 기록. 온라인에서는 자율 행동하지 않음.
8. 하준 의상 → 사용자 제공 사진 하단 오른쪽 남학생 하복: 노란 반팔, 짙은 회색 반바지, 흰 양말/운동화. 여름은 검정 머리와 주황 옷을 유지.

아직 남은 한계 — 수정 완료로 간주하지 않음
- 해변과 정글은 큰 그림 두 장 기반. 원래 이미지의 고정 포말, 나뭇잎, 바위 경계가 포함되어 있다. 진짜 수면/해변/암석/식생 레이어 분리 자산으로 교체해야 일관된 환경 움직임이 가능하다.
- 일부 전경 잎 경계와 두 배경 연결부가 부자연스럽다. 구간별 배경과 가림 처리를 다시 구성할 필요가 있다.
- 2D 좌우 반전 중심 캐릭터라 위/아래/대각선 전용 자세가 없다. 8방향 리깅 수준이 아니다.
- 낚시의 장대는 아직 선으로 그린 전용 표현이며 보유 아이콘과 형태가 완전히 같지 않다.
- 물 채우기/먹기/요리/창 찌르기 각각의 긴 전용 프레임이 아직 부족하다. 모든 행동의 자연스러움 검증을 완료했다고 말할 수 없다.
- 여름 NPC는 탐사/이동/대화 동료이며 자율 수집·제작·전투는 아직 하지 않는다.
- 큰 지도는 해변–정글의 가로 탐험 구성이며 동물의 숲처럼 자유 지형 편집이나 99나이트식 매번 생성되는 방사형 맵은 아니다.
- 목소리/실기기 터치/협동 장시간 플레이의 시청각 검증은 이번 범위에서 완료하지 않았다.

개선 우선순위
1. 캐릭터 발 기준·손잡이·각 동작의 접촉 순간을 실제 화면으로 반복 검증.
2. 방향별 자세와 행동별 프레임을 늘리고, 발이 미끄러지지 않게 이동 거리와 보폭을 맞춤.
3. 정적 배경을 수면/포말/모래/고정 장애물/전경 식생으로 분리해 재제작.
4. 지역별 탐험 목적, 수집·전투·귀환 보상 흐름, NPC 협력 행동 확장.

최종 확인 결과
- 하준 추가 동작 32프레임: 걷기 8, 달리기 8, 도끼 사용 8, 삽질 8. 기존 표정·기타 행동 24프레임은 별도 시트로 유지.
- 실제 게임에서 서기/걷기/장착 모습과 양쪽 캐릭터의 신발, NPC 이동을 화면으로 확인. 모든 프레임을 연속 재생해 모든 방향/모든 도구 조합까지 검증한 것은 아니다.
- 가죽 조끼를 몸통에 아이템 그림으로 표시하도록 변경. 토끼의 뜀 높이와 멧돼지의 낮은 몸 흔들림, 정지 시 호흡을 구분.
- 파도 직사각형 띠의 반복 무늬를 연속 면과 불규칙 포말로 다시 수정. 고정 배경의 원래 파도는 남아 있음.
- 상황별 원본 합성 음악 네 가지(해변/정글/밤/위험) 구현. 외부 게임 음원 사용 없음. 모든 실제 모바일 기기에서 청취 검증한 것은 아님.
- 실제 기기에 .island.json 다운로드 확인. 같은 파일을 파일 선택 창으로 불러와 '1일차 기록을 불러왔어요' 확인. 날짜/장비/위치/재료 및 제작 중 저장 복원은 자동 테스트 통과.
- 전체 자동 테스트 37개 통과. TypeScript 검사와 프로덕션 빌드 통과.
- 125.176.45.19:7749 외부 HTTP health 및 게임 화면 접속 확인. 두 WebSocket 플레이어 협동 참여 확인. systemd 사용자 서비스 활성화, 재부팅 자동 시작.
- 서버에서 ws 의존성 설치 누락을 발견하고 npm install --omit=dev --ignore-scripts로 해결.
- localhost의 기존 자동 저장은 서버 주소로 자동 복사되지 않음. 로컬 게임에서 파일 저장 후 서버 게임에서 불러와야 함.
