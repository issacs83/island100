무인도 100일 — 플레이 감각 재기획 / 2026-10-04

목표: 버튼의 즉시 보상보다 도구 선택, 대상 관찰, 예비 동작, 실행, 반응, 보관이 읽히는 게임.

참고 자료
Nintendo 공식 낚시 가이드: https://play.nintendo.com/news-tips/tips-tricks/fishing-new-horizons-tips-and-tricks/
물고기 그림자 관찰, 찌 앞에 캐스팅, 입질의 시청각 신호, 잠기는 순간 입력, 잡은 물고기 제시가 핵심이다.
99 Nights 커뮤니티 캠프 설명: https://99-nights-in-the-forest.fandom.com/wiki/Campfire
캠프를 거점으로 탐험해 자원을 회수하고 강화하며 활동 영역을 넓히는 흐름을 참고한다. 공식 세부 설계 자료가 아닌 커뮤니티 자료이다.

이번 구현
가방: 도구를 별도 격자에 배치, 현재 장착 표시, 손에 들기/넣기. 13종 도구 제작.
낚시: 낚싯대 장착 필수. 미끼 소비. 던지기 0.7초, 기다림 1.6~3초, 입질 입력 1.6초, 끌어올리기 1.1초, 제시 1.2초 후 보관. 조기 입력/시간 초과 실패.
사냥: 동물의 숲에는 이런 동물 사냥이 없으므로 별도 설계. 0.55초 동작 중 0.28초에 타격 판정. 시야와 사거리 검사, 활은 조준점에서 달아나면 빗나감. 준비 동작 중 이동·장착 변경 제한.
삽질: 해변/정글의 흙더미에 삽 필요. 흙 튀김, 몸 기울임, 도구 회전. 한 지점 6번 채집. 돌과 미끼 획득.
채집: 줍기 몸 낮춤, 중복 입력 방지. 나무를 벤 후 목재를 다시 클릭해 회수.
탐험: 기존 공유 안개 지도와 우회 경로에 캠프 3단계 정비 추가. 목재 10/20개, 캠프 근처에서만 가능. 주변 지도 정보 확장.
환경: 바람에 위상차를 둔 잎/풀, 날리는 잎, 파도 포말, 미세한 숨쉬기와 머리카락 끝. 고정 배경의 바위/텐트는 변형하지 않는다. 잎 추출 경계 페더링과 캠프 인접 추출층 제거.

정확한 현재 범위
지형 자체는 기존 해변/정글 가로형 맵이다. 99 Nights처럼 절차 생성되는 방사형 섬이나 캠프 레벨로 지형 자체가 열리는 구조는 아직 구현되지 않았다.
캐릭터 동작은 기존 픽셀 프레임에 도구/자세 애니메이션을 결합했다. 완전한 관절 리깅이나 동작별 전용 손·팔 스프라이트는 아니다.
자연 효과는 2D 레이어와 입자 기반이며 실제 유체/머리카락 물리나 레이트레이싱은 아니다.

후속 지도 제작 기준
캠프 주변 작은 순환 채집로 → 해변 낚시/숲 사냥/동쪽 샘 분기 → 깊은 정글 원정의 거리와 위험 단계.
갈림길마다 랜드마크와 돌아오는 지름길을 둔다. 배경 아트도 바닥·물·바위·나무 줄기·수관으로 분리 제작해 지형과 물리 경계를 일치시킨다.
