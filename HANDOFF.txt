9. 실행/검사/배포
서버 Ubuntu22.04/ARM64, Node22.23.3(/usr/bin/node). 실행 소스와 빌드 release를 구분한다.
소스에서 npm install 후 npm run build, npm test, node scripts/build-server.mjs.
잠금 파일 pnpm-lock.yaml을 포함했으므로 설치 방식/새 잠금 파일 변경은 기록한다.
로컬 npm이 없는 경우 기존 Node 경로로 실행 가능:
PATH=/Users/jun/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH
node node_modules/typescript/bin/tsc --noEmit
node node_modules/tsx/dist/cli.mjs --test tests/*.test.ts
node node_modules/vite/bin/vite.js build
node scripts/build-server.mjs
소스 묶음 무결성: node scripts/source-manifest.mjs <소스 디렉터리>로 SHA-256 목록 생성,
서버 스냅샷 안에서 sha256sum -c SOURCE-MANIFEST.sha256으로 파일 전체 확인.
node_modules를 Mac에서 ARM 서버로 복사하지 않는다. 대상 서버에서 의존성을 설치한다.
서비스 환경: HOST=0.0.0.0 PORT=7749 DATA_DIR=/home/issacs/island100/data.
빌드 파일은 사용자 systemd 서비스의 WorkingDirectory 아래 server.mjs와 dist/에 배포.
배포 전 기존 실행 묶음을 보관하고, 데이터 디렉터리는 덮어쓰지 않는다.
systemctl --user restart island100.service 후 curl -fsS http://127.0.0.1:7749/health 와 실제 브라우저 확인.
소스 스냅샷은 코드/그림/음성/테스트/기획/lockfile 포함, node_modules/dist/release/data 제외.
handoff/current는 같은 스냅샷을 가리킨다. 문서와 소스는 SSH로 읽는 서버 디렉터리에 있다.
이후 갱신은 새 스냅샷 생성→검증→current 링크 갱신, 이전 스냅샷 보존.
