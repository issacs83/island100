무인도 100일 — 레퍼런스 게임 3종 적용 기획 (2026-10-05)
대상: 데이브 더 다이버: 인 더 정글 / 모여봐요 동물의 숲 해피 홈 파라다이스(HHP) / 99 Nights in the Forest(Roblox)
원칙: 야외는 끊김 없는 하나의 섬. 집 실내만 별도 화면. 섬 안의 구분은 빛 반경·안개·지형 장애물로만 한다.
표기: [확인] 출처 문서에서 확인, [추정] 비공식 위키/리뷰 기반 또는 미확인.

1. 게임별 장점 요약
1-1. 데이브 더 다이버 (+ 인 더 정글 DLC, 2026-06-18 출시)
- 하루 = 낮 수집(잠수·채집) → 밤 경영(초밥집/Bancho Grill). 낮의 수집이 곧 밤의 재료. [확인]
- 산소 게이지가 시간과 체력을 겸함. 적재 무게 한도가 귀환 판단을 만든다. [확인]
- 스마트폰 앱 메뉴로 업그레이드·도감·의뢰를 묶는다. [확인]
- 도구: 기본 작살 + 보조무기 1 + 아이템 2 로드아웃. DLC Jungle Gun은 무기 1개를 Rifle/Shotgun/Sniper/Net 4모드로 전환, 업그레이드 트리 초기화 가능. [확인]
- 연출: 예비동작 → 명중 → 끌어오기, 과장된 픽셀 컷신. 획득 아이콘이 날아가는 피드백. [추정 일부]
- 맵: 고정 랜드마크 + 세부 배치 랜덤(블루홀). DLC는 탑다운 마을 허브 + 사이드뷰 잠수(구획형).

1-2. 해피 홈 파라다이스
- 의뢰인 테마 + 필수 가구 → 자유 배치 → 실패 없는 칭찬 → 꾸미기 기능 단계 해금. [확인]
- 격자 스냅 꾸미기, 칸막이 벽·카운터·기둥, 조명 색/밝기, 환경음(사운드스케이프) 프리셋. [확인]
- 가구 상호작용(앉기/눕기/켜기/연주)과 조명·소리로 같은 방의 분위기를 바꾼다. [확인]
- 시설을 꾸미면 매일 보상(레시피/아이템)으로 순환. [확인]
- UI: 카테고리 탭 + 썸네일 그리드, 집기→이동→회전 3동작. [추정: 터치 적합성]

1-3. 99 Nights in the Forest
- 모닥불 = 안전지대 = 탐험 범위. 불 레벨이 오르면 빛 반경·지도 공개 범위가 넓어진다. 꺼지면 안전지대와 지도 상실. [확인, 수치는 추정]
- 비가 오면 불 레벨이 떨어지고 장작이 젖는다. [추정]
- 작업대 Lv1~5 단계 해금(지도·덫 → 바리케이드·침대 → 요리·레이더 → 텔레포터…). [추정 수치]
- 지도·나침반·해시계·레이더를 제작해야 HUD 정보가 늘어나는 "정보 = 보상" 구조. [확인]
- 실종 아동 구출: 불 레벨이 동굴 접근을 열고, 수호 동물 처치 열쇠로 연다. 구출 시 진행 배율 증가. [추정 수치]
- 맵: 하나로 이어진 숲 중앙의 캠프, 동심원 확장, 거점(동굴·폐허·상자)을 안개 해제로 발견. [확인]

2. 무인도 100일 적용 우선순위
P0 (이번 단계부터)
- [완료 2026-10-05] 끊김 없는 섬 지면: 원본 해변/정글 그림 경계 노이즈 페더, 미러 타일 지면, 대칭 깨기 패치,
  연속 해안·바다, 코드 길(trails)과 그림 길 일치. 출처: 99 Nights 연속 숲.
- 캠프 모닥불 Lv1~5: 연료(목재/코코넛 껍질) 투입 → 연소 타이머 → 밤 안전 반경·지도 공개 반경 확대.
  꺼지면 밤 몬스터가 캠프로 접근. 비 오는 날 레벨 하락. 출처: 99 Nights.
- 낮 수집 → 해질녘 정비 루프: 300초 중 0~200초 탐험, 200~300초 캠프 요리/제작/집 정비 권장.
  가방 무게 한도와 "귀환" 판단. 출처: 데이브.
- 도구 3단계 모션 규격: 예비동작(2~3프레임) → 접촉(히트스톱 60~80ms, 파편/먼지) → 회복(3~4프레임),
  보상 아이콘이 가방으로 날아감. 13종 공통. 출처: 데이브.
P1
- 단계형 제작대 Lv1~4: 나무 도구 → 돌 도구/횃불 → 병·냄비·바구니 → 활. 지도/나침반/해시계는 제작품. 출처: 99 Nights.
- 여름이 찾기/친구 구출 거점: 불 레벨로 동굴/폐허 접근 해금, 동물 수호자. 출처: 99 Nights.
- 모드 전환 도구: 창 찌르기/던지기, 활 일반/불화살, 업그레이드 트리(초기화 가능). 출처: 데이브 Jungle Gun.
- 실내 격자 꾸미기 고도화: 카테고리 탭, 길게 눌러 집기, 회전, 칸막이·조명·환경음 단계 해금. 출처: HHP.
- 의뢰형 꾸미기: 여름이/친구의 테마 부탁("낚시꾼 방" 등) + 필수 가구 → 실패 없는 칭찬 + 기능 해금. 출처: HHP.
P2
- 협동 역할(나무꾼/사냥꾼/요리사 패시브), 쓰러진 친구 부축. 출처: 99 Nights.
- 랜드마크 고정 + 자원/상자 위치 일일 변동. 출처: 데이브 블루홀.
- 정보 HUD 단계 공개(해시계→시계, 나침반→방향). 출처: 99 Nights.
- 실내 조명/환경음 프리셋(파도·빗소리·모닥불). 출처: HHP.

3. UI/애니메이션 규칙 (전 기능 공통)
- 모바일 중앙 조작 공간 유지. 상호작용 버튼 하나에 문맥 행동(살펴보기/베기/파기).
- 위험 예고: 몬스터 돌진 전 경고 아이콘과 소리(99 Nights). 빛 경계 밖은 어둡게.
- 획득 피드백: 아이콘 비행 + 수량 팝업, 첫 획득은 도감 카드.
- 꾸미기 UI는 실내 주 화면 위에서만 열림(팝업으로 되돌리지 않음).
